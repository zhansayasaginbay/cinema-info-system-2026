# Кинотеатрдың ақпараттық жүйесінің Use Case сипаттамасы

## Әкімші

Әкімші жүйеге фильмдерді қосады, өзгертеді және өшіреді. Сонымен қатар киносеанстар мен залдар туралы ақпаратты басқарады.

## Кассир

Кассир фильмдер мен сеанстар туралы ақпаратты қарайды және клиенттерге билеттерді рәсімдейді.

## Көрермен

Көрермен фильмдерді қарайды, қажетті сеансты таңдайды, залдағы бос орынды таңдайды және билет брондайды.

## Негізгі Use Case әрекеттері

- Жүйеге кіру;
- Фильмдерді қарау;
- Фильм қосу;
- Фильмді өзгерту;
- Сеансты таңдау;
- Бос орынды таңдау;
- Билет брондау;
- Билет туралы ақпаратты қарау.
